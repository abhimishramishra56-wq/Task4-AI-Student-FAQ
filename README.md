# AI Student FAQ Assistant

## Project Overview
AI Student FAQ Assistant is a beginner-friendly application built using Python and Streamlit. It answers basic questions related to Artificial Intelligence, Python, Machine Learning, and Data Science.

## Problem Statement
Beginners often have difficulty understanding basic AI and Data Science concepts. They need a simple application that can provide quick answers to common questions.

## Methodology
- Python is used to develop the application.
- Streamlit is used to create the user interface.
- The user enters a question into the input box.
- The application matches the question with predefined answers.
- If a matching question is found, the answer is displayed.
- If no matching answer is found, the application displays a message.

## Features
- Simple and beginner-friendly interface.
- Answers basic AI-related questions.
- Supports predefined questions.
- Instant response for supported questions.
- Easy to run locally.

## Demo
The application allows users to enter questions such as:
- What is AI?
- What is Python?
- What is Data Science?
- What is Machine Learning?
- What is NLP?
- What is Deep Learning?

The answer is displayed on the screen after clicking the Get Answer button.

## Limitations
- It only answers questions available in its predefined database.
- It does not understand every question.
- It does not use a trained machine learning model or generative AI.
- Answers are limited to the information programmed into the application.

## Ethical Considerations
- Users should not blindly trust automated answers.
- Incorrect or incomplete information may be provided.
- No sensitive personal information should be entered.
- AI should be used responsibly and as a learning-support tool.

## Technologies Used
- Python
- Streamlit

## Installation and Usage

1. Install Python.
2. Install Streamlit:

   pip install streamlit

3. Download or clone the repository.
4. Open the project folder in CMD.
5. Run the application:

   python -m streamlit run app.py

6. Open the local URL provided in the terminal.

## Conclusion
This project demonstrates how a simple Python application can be used to create an interactive FAQ assistant. It provides a beginner-level understanding of application development, user input, conditional logic, and interface design.
